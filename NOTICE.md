SubtitleForge is a new provider-driven Python service and MoviePilot adapter. It
does not include the stopped ChineseSubFinder Go application. Its credential-free
Xunlei and optional Shooter fingerprint protocols were reimplemented in Python
from the MIT-licensed upstream source.

MoviePilot V3 plugin contracts were used as the compatibility target:

<https://github.com/jxxghp/MoviePilot>
<https://github.com/jxxghp/MoviePilot-Plugins>
